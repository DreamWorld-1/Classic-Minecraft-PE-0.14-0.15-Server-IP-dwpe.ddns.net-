## 🚀 Как начать играть?

1. **Установите клиент** для вашей архитектуры: **Megacraft** или **Minecraft PE 0.15.10**.
2. **Заходите на сервер** по указанному IP.
3. **Регистрируйтесь**, чтобы защитить свой аккаунт.
4. Введите `/kit start`, чтобы получить стартовый набор.
5. Зарабатывайте на `/warp mine` и `/warp farm`, сдавайте ресурсы скупщику через `/sell`.
6. Исследуйте мир через `/rtp` и развивайтесь как душе угодно!
